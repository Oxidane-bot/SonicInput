# v0.7.8 - Fluent UI only and history reliability fixes

## 中文

### 亮点
**Fluent UI 收敛**
- 设置、历史、详情、批量重处理和录音悬浮窗均收敛到 Fluent/QML 表面。
- 删除旧 QWidget 设置窗口、设置 tabs、历史详情、批量重处理对话框、旧录音悬浮窗和旧 overlay 组件。
- 启动诊断、主入口、托盘和 UI 包导出不再指向旧 UI。

**历史记录**
- 修复长中文历史摘要在窄窗口下覆盖状态和详情按钮的问题。
- 历史列表摘要固定为单行省略，详情按钮高度与状态标签对齐。
- 历史重转录不再触发录音悬浮窗或实时录音 UI 事件。

**AI 优化**
- 检测 AI 服务返回 `finish_reason=length` 的截断输出。
- 截断时回退到完整原始转写，并把 AI 状态记录为失败，避免把少一大段的 AI 文本写入历史或输入目标窗口。
- 新增 `ai.max_output_tokens` 配置，默认 4096。

**验证**
- 增加 AI 截断、历史重处理事件隔离、旧 UI 禁用和 Fluent/QML 历史布局回归测试。
- 更新视觉审计，覆盖设置页、历史页、详情、空态、批处理确认/进度和录音悬浮窗。

### 发布产物
- `SonicInput-v0.7.8-win64.exe`
- 离线包仅在本地模型目录可用时生成。

### 升级步骤
1. 下载 `SonicInput-v0.7.8-win64.exe`。
2. 关闭旧版本并替换可执行文件。
3. 配置和历史记录保持兼容。

## English

### Highlights
**Fluent UI only**
- Settings, History, details, batch reprocessing, and the recording overlay now use the Fluent/QML surfaces.
- Removed the legacy QWidget settings window, settings tabs, history detail dialog, batch reprocess dialog, old recording overlay, and old overlay components.
- Startup diagnostics, main entry points, tray code, and UI package exports no longer point to legacy UI modules.

**History**
- Fixed long Chinese history rows overflowing into status text and detail buttons in narrow windows.
- History summaries are single-line ellipsized, and detail buttons align with status labels.
- History retranscription no longer triggers the recording overlay or live recording UI events.

**AI optimization**
- Detects AI responses truncated with `finish_reason=length`.
- Falls back to the full original transcription and records AI status as failed, preventing truncated AI text from being saved or typed.
- Added `ai.max_output_tokens`, defaulting to 4096.

**Validation**
- Added regression coverage for AI truncation, history reprocess event isolation, legacy UI removal, and Fluent/QML history layout.
- Expanded visual audit coverage for settings, history, details, empty state, batch confirmation/progress, and recording overlay.

### Artifacts
- `SonicInput-v0.7.8-win64.exe`
- Offline bundle only when a local model directory is available.

### Upgrade Steps
1. Download `SonicInput-v0.7.8-win64.exe`.
2. Close the old version and replace the executable.
3. Existing configuration and history data remain compatible.
