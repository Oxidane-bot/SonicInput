# v0.8.0 - AI quality guardrails, Review Agent, and long-recording diagnostics

## 中文

### 亮点
**AI 输出安全门禁**
- 新增 `TranscriptQualityValidator`，在 AI 清理结果进入最终输入前进行本地审查。
- 拦截 markdown/列表/代码块、`Input/Output/Analysis` 标签泄漏、助手式回答或拒答、翻译命令越界、意外语言切换、短噪声扩写、长文本过度压缩和异常重复。
- 验证失败时不会把坏输出输入到目标窗口，而是记录具体原因并回退到原始转写。

**长语音上下文一致性**
- 新增录音内 `RollingTranscriptContext`，按录音会话维护最近片段、路径、英文术语、项目名和技术词。
- 后续分块 AI 清理会收到短上下文附录，用于保持术语一致；上下文只作为保守参考，不允许模型回答、翻译或执行命令。
- 支持已接受的本地词汇记忆参与 AI 清理提示词，但默认仍由 validator 兜底。

**Quality Review 与本地词汇记忆**
- 新增 `HistoryReviewAgent`、`ReviewSchedulerService` 和 `ReviewStorageService`，可从最近历史中发现质量建议。
- 设置窗口新增 Quality Review 页面，按“边界越界 / 内容失真 / 诊断样本 / 词汇记忆 / 提示词问题”组织建议。
- 用户可接受、拒绝、忽略或归档建议；只有接受的术语候选会写入本地词汇记忆。
- 支持导出词汇记忆、导出 prompt/validator 调试报告、清空词汇记忆和清空学习数据。
- 空闲自动审查默认关闭；可手动运行，避免影响实时输入路径。

**长录音云转写路径与历史可观测性**
- 新增 `transcription.long_recording.prefer_file_for_cloud` 和 `file_threshold_seconds`，云端长录音默认 90 秒以上优先走文件转写路径。
- 历史库 schema 增加 `transcription_path`、`transcription_decision_reason`、`fallback_type` 等字段，UI 中可查看转写路径、决策原因和 fallback 类型。
- chunked 结果低质量或空结果时的 fallback 记录更明确，便于排查“长录音为什么走了哪条路径”。

**质量审计与 prompt 实验工具**
- 新增隐私安全审计脚本：`scripts/audit_transcript_quality.py`，默认只输出元数据、长度、状态、路径和异常标签，不保存转写原文。
- 新增 `scripts/compare_quality_audits.py` 用于 before/after 指标对比。
- 新增 `scripts/evaluate_ai_prompt_profiles.py` 和版本化 prompt profiles（baseline / strict_cleaner / long_dictation_preserve / short_noise_safe / context_aware）。
- `quality_audit/` 已加入 git ignore，避免本地历史审计产物误提交。

**默认体验调整**
- 默认热键改为 `Ctrl+Alt+Space`，减少与常见编辑快捷键冲突。
- 配置示例同步新增长录音、Review 和本地学习相关选项。

### 测试与验证
- 新增/扩展测试覆盖：AI 输出 validator、prompt profiles、rolling context、Review Agent、Review storage/scheduler、Review UI、转写路径可观测性、长录音 fallback、历史 schema 升级。
- 建议发布前运行：
  - `uv run ruff check src tests`
  - `uv run pytest -m "not gui and not gpu and not e2e" -v`
  - `uv run --group dev python build_nuitka.py`

### 发布产物
- `SonicInput-v0.8.0-win64.exe`
- 离线包仅在本地模型目录可用时生成：`SonicInput-v0.8.0-win64-offline.zip`

### 升级步骤
1. 下载 `SonicInput-v0.8.0-win64.exe`。
2. 关闭旧版本并替换可执行文件。
3. 配置和历史记录会自动兼容；首次打开历史库时会补齐新增诊断字段。
4. 如需使用 Quality Review，可在设置页手动运行审查；空闲自动审查默认关闭。

## English

### Highlights
**AI output quality gate**
- Added `TranscriptQualityValidator` to validate AI cleanup before it becomes final inserted text.
- Rejects markdown/lists/code fences, `Input/Output/Analysis` label leaks, assistant-style answers/refusals, translation-command leaks, unexpected language shifts, short-noise expansion, over-compressed long dictation, and abnormal repetition.
- Failed validation records a concrete reason and falls back to the raw transcript instead of inserting unsafe AI output.

**Consistent long-dictation cleanup**
- Added per-recording `RollingTranscriptContext` for recent snippets, paths, English terms, project names, and technical vocabulary.
- Later chunk cleanup receives a short context appendix to keep terminology consistent; the context is conservative and explicitly forbids answering, translating, or executing commands.
- Accepted local lexicon memory can be included in cleanup prompts, with the validator still acting as the final safety net.

**Quality Review and local lexicon memory**
- Added `HistoryReviewAgent`, `ReviewSchedulerService`, and `ReviewStorageService` for local history-based quality suggestions.
- Added a Quality Review page in settings, grouping suggestions by boundary violations, content distortion, diagnostic samples, lexicon learning, and prompt-quality issues.
- Users can accept, reject, ignore, or archive suggestions. Only accepted terminology candidates are written into local lexicon memory.
- Supports lexicon export, prompt/validator debug-report export, clearing lexicon memory, and clearing learning data.
- Idle auto-review is disabled by default and can be run manually so it does not affect the hot input path.

**Long-recording cloud path and history observability**
- Added `transcription.long_recording.prefer_file_for_cloud` and `file_threshold_seconds`; cloud recordings longer than the default 90 seconds prefer file transcription.
- History schema now stores `transcription_path`, `transcription_decision_reason`, `fallback_type`, and related diagnostics; the UI displays path, decision reason, and fallback type.
- Chunked fallback records are more explicit, making it easier to diagnose which transcription path was chosen for long recordings.

**Quality audit and prompt experiments**
- Added privacy-safe audit script `scripts/audit_transcript_quality.py`, which stores metadata, lengths, status, paths, and anomaly labels without transcript text by default.
- Added `scripts/compare_quality_audits.py` for before/after metric comparisons.
- Added `scripts/evaluate_ai_prompt_profiles.py` plus versioned prompt profiles: baseline, strict_cleaner, long_dictation_preserve, short_noise_safe, and context_aware.
- `quality_audit/` is git-ignored to avoid committing local history-derived artifacts.

**Default experience updates**
- Changed the default hotkey to `Ctrl+Alt+Space` to reduce collisions with common editing shortcuts.
- Updated example config with long-recording, Review, and local-learning options.

### Tests & Validation
- Added/expanded tests for AI output validation, prompt profiles, rolling context, Review Agent, Review storage/scheduler, Review UI, transcription-path observability, long-recording fallback, and history schema upgrades.
- Recommended release checks:
  - `uv run ruff check src tests`
  - `uv run pytest -m "not gui and not gpu and not e2e" -v`
  - `uv run --group dev python build_nuitka.py`

### Artifacts
- `SonicInput-v0.8.0-win64.exe`
- Offline bundle only when a local model directory is available: `SonicInput-v0.8.0-win64-offline.zip`

### Upgrade Steps
1. Download `SonicInput-v0.8.0-win64.exe`.
2. Close the old version and replace the executable.
3. Existing config and history data remain compatible; the history DB is upgraded with the new diagnostic fields on first use.
4. Run Quality Review manually from settings if desired; idle auto-review remains disabled by default.
