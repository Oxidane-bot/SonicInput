# SonicInput v0.8.1 Release Notes

Release date: 2026-07-12

## Highlights

- Promoted Local Lexicon Memory to a top-level settings page. Candidates and saved vocabulary now use separate tabs and independently scrolling lists.
- Made History refresh whenever the page is entered, re-entered, or selected again. Pagination now prefetches until the viewport is filled.
- Tightened lexicon review to extract the smallest complete reusable term instead of saving surrounding context.
- Added deterministic provenance checks: every candidate must cite existing raw transcription records that contain the proposed mistaken form.
- Added controlled homophone and near-homophone acceptance while rejecting semantic jumps, cross-script pairs, formatting-only changes, and unsupported evidence.
- Fixed runtime recall after lexicon edits through explicit cache invalidation, removed the fixed active-entry limit, and allowed multiple mistaken forms for one canonical term.
- Fixed the Windows onefile package to include pypinyin dictionaries, staged QML plugins, and their required Qt runtime libraries.
- Fixed the pynput event-filter closure so packaged hotkey handling does not repeatedly fail on an unbound `time` import.

## Interaction Changes

- Removed the nested Local Vocabulary card from AI Processing.
- Removed the secondary-page state, Manage entry, and Back button. Local Lexicon Memory is now always visible in the primary navigation.
- Accepting, rejecting, ignoring, or removing an item preserves the active list's scroll position.
- Candidate and saved-vocabulary scrolling no longer moves the surrounding page.

## Upgrade Notes

- This release intentionally hard-cuts the obsolete review implementation. If the review/lexicon schema is incompatible, its tables are rebuilt rather than migrated.
- Existing v0.8.0 pending review candidates and accepted local lexicon entries are not guaranteed to survive the schema rebuild. Export the lexicon before upgrading if those entries are needed.
- Pending candidates generated by pre-v3 review prompts are archived and no longer shown.
- Application configuration and transcription history are not part of the review schema rebuild.
- Automatic lexicon review remains disabled by default. Accepted lexicon memory remains enabled by default.
