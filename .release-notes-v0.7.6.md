# v0.7.6 - Fluent History 页面修复

## 中文

### 亮点
**Fluent History**
- 修复 Fluent 设置窗口中的历史页面，恢复真实历史记录加载、搜索、统计和 keyset 分页。
- 重新接通历史详情、删除、重试，以及批量重新处理流程；重试仍会创建新的重处理记录并保留原始记录。
- 补充 Fluent History 回归测试和 QML E2E 覆盖，防止页面退回静态占位。

### 发布产物
- `SonicInput-v0.7.6-win64.exe`
- 如本地模型目录可用，将同时提供 `SonicInput-v0.7.6-win64-offline.zip`

### 升级步骤
1. 下载 `SonicInput-v0.7.6-win64.exe`。
2. 关闭旧版本并替换可执行文件。
3. 配置和历史记录保持兼容。

## English

### Highlights
**Fluent History**
- Fixed the Fluent settings History page so it loads real history records, search results, statistics, and keyset pagination again.
- Reconnected history detail, delete, retry, and batch reprocess flows; retry still creates a new reprocessed record while preserving the original record.
- Added Fluent History regression and QML E2E coverage so the page cannot silently fall back to a static placeholder.

### Artifacts
- `SonicInput-v0.7.6-win64.exe`
- `SonicInput-v0.7.6-win64-offline.zip` when a local model directory is available

### Upgrade Steps
1. Download `SonicInput-v0.7.6-win64.exe`.
2. Close the old version and replace the executable.
3. Existing configuration and history data remain compatible.
